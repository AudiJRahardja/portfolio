The Grand Treasure Raid

A Discord-login puzzle event site for BINUS Game Development Club, with checkpoints that unlock on a schedule and a live leaderboard.

Oct 2026

Live demo for The Grand Treasure Raid (opens in a new tab)Code for The Grand Treasure Raid (opens in a new tab)

Problem

The club wanted a recurring online puzzle event for its Discord community that is fair, hard to cheat and easy for organisers to run.

Approach

  • Discord sign-in, with BGDC guild membership verified on the server.
  • Four puzzle types (riddle, sudoku, queens, crossmath) with drag-and-drop interfaces.
  • Puzzle uniqueness checker and crossmath generator, with tests.
  • Scheduled checkpoint unlocks, timed submissions and a leaderboard ranked by points, then solve time.
  • Row-level security migrations and a written security review.

My role

Everything: design, build, security hardening and deployment.
