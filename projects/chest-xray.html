Chest X-ray Classification

A planned CNN that sorts chest X-rays from the COVID-19 Radiography Database into their diagnosis classes.

The problem

Reading chest X-rays takes a trained radiologist's time. This course project plans to train a convolutional neural network (CNN) to sort X-rays from a public database into their diagnosis classes, and to check how reliable it is.

How it works

5 stages, 5 still planned (dashed). Pick a stage to see what goes in, what happens and what comes out. Arrow keys move between stages.

Stage 01 of 05

Images

Planned
Input

The public COVID-19 Radiography Database of chest X-rays

Operation

Download it and split it into training, validation and test sets

Output

Not known yet

  • Planned. Nothing has been built yet.
  • The test set stays untouched until the final evaluation.

Flow: download_dataset >> split(train, val, test)

Stage 02 of 05

Preprocess & augment

Planned
Input

Raw X-ray images of different sizes

Operation

Resize and normalise every image; add small random changes (augmentation) to the training images

Output

Model-ready image batches

  • Planned.
  • Augmentation gives the model more variety to learn from without collecting new images.

Flow: resize >> normalise >> augment >> batch

Stage 03 of 05

Train CNN

Planned
Input

Training and validation batches

Operation

Train a convolutional neural network to predict each image's class

Output

A trained model

  • Planned.
  • The exact CNN and the baseline to compare it with are still to be chosen.

Flow: build_cnn >> fit >> save_best

Stage 04 of 05

Evaluate

Planned
Input

The held-out test set

Operation

Measure how often the model is right for each class, next to a simple baseline

Output

Not known yet

  • Planned.
  • Results will be shown per class, because the classes are not the same size.

Flow: predict(test) >> per_class_report >> compare_baseline

Stage 05 of 05

Predictions

Planned
Input

A new chest X-ray

Operation

Output

  • Planned.
  • For learning only, not for medical use.

Flow: load_image >> preprocess >> model.predict
