I'm a Computer Science student at BINUS University (School of Computer Science, 5th semester), specialising in Artificial Intelligence. Most of my projects begin with a question like “how well does this actually work?”, so I build an evaluation set before I trust a number.

I started out writing small console programs in C in my first semester, and I still practise algorithms on Codeforces. These days I work mostly on speech, NLP and retrieval systems. Outside class I help run the BINUS Game Development Club community.
